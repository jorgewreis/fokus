## Critérios de transição
1. Preservar código, bancos, histórico, automações e ambientes existentes.
2. Inventariar dependências antes de migrar aplicações.
3. Não copiar credenciais, dados pessoais ou segredos para este repositório.
4. Tratar a 1ª Vara Crime de Ilhéus como P0, meta de MVP 31/01/2027.
5. Aceitar implantação da governança apenas quando não houver pendências no escopo definido (meta 15/12/2026).
6. Não automatizar merge/deploy sem gates FEKS e autorização válida.
