## Comparação local/remoto de `fokus`

Na verificação de 2026-11-23, `git ls-remote origin refs/heads/main` retornou `010ff6087c355c2cd6abdf86733636717d91291f`; no checkout legado `D:\Projects\Clients\fokus`, `git rev-list --left-right --count HEAD...origin/main` retornou `0 39`. `git show origin/main:<arquivo>` foi usado para leitura sem atualizar aquele worktree. A documentação em `worktrees/fokus-portfolio` parte da ponta remota, em branch separada. O CI na ponta remota roda validação Composer, instalação Node, build Vite, testes Laravel e um smoke Docker Compose sintético; isso descreve automação configurada, não resultado recente nem deploy. O `apps/law/` no checkout legado não deve ser usado para estimar o estado atual do código institucional.

No checkout local, `apps/law/composer.json` declara PHP `^8.3` e Laravel `^13.17`, enquanto o README pede PHP 8.5; o workflow local ainda só valida Composer e executa testes. A ponta remota inclui mais capacidades e um fluxo de CI mais abrangente. Essa diferença precisa ser tratada na reconciliação de branches, sem copiar ou remover código antes de confirmar a fronteira do repositório e a estratégia de separação institucional.
